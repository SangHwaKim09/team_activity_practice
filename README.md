# team_activity_practice
과제 1-3 팀 저장소 협업 과제 연습용 레포지토리

## 구현 내용
- GitHub에 연습용 공개 저장소를 만들고 clone 한 뒤, README.md 에 배달 로봇 사양(센서 목록·주기)을 적어 첫 커밋을 push 하세요.

- feature/compute-layout 브랜치를 만들어 문제 1의 연산 분담 설계 문서를 커밋하고, feature/udev-rules 브랜치에 문제 2의 규칙 파일과 키 설명표를 커밋하세요.
- 두 브랜치 중 하나로 Pull Request 를 열어 스스로 리뷰 코멘트를 1개 이상 달고, 그 지적을 반영한 커밋을 추가한 뒤 병합하세요.
- 별도 브랜치 두 개(branch-a, branch-b)에서 README.md 의 같은 줄을 서로 다르게 수정해 의도적으로 conflict 를 만들고, 충돌 표식(<<<<<<<, =======, >>>>>>>)이 각각 무엇을 뜻하는지 설명한 뒤 해결하세요.
- 나머지 한 브랜치는 병합 전에 git rebase main 으로 최신화하고, git log --oneline --graph 출력을 merge 방식과 나란히 비교해 이력 모양이 어떻게 다른지 서술하세요.
- 언제 merge 를, 언제 rebase 를 쓸지 팀 규칙 관점에서 정리하세요.
